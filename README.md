# Kinetic UI — Awwwards-tier Animated Component Library

A modern, high-performance UI interaction and animation laboratory built with React 19, TypeScript, Tailwind CSS, Framer Motion, and Razorpay integration.

## Features
- **Live Interactive Components**: 60fps spring physics, 3D hologram tilt, magnetic cursor effects, radar scans, laser border-beam bento cards.
- **Awwwards Archive**: Categorized motion references (Hero, Scroll, WebGL, 3D, Page Transitions).
- **Multi-Framework Code Inspection**: Instant copy for React (Framer Motion), Tailwind CSS, and Vanilla HTML/CSS.
- **Razorpay Checkout**: End-to-end payment flow for PRO access with tokenized ZIP archive downloads.

## Getting Started

### 1. Install dependencies
```bash
npm install
```

### 2. Configure environment
Create a `.env` file based on `.env.example`:
```env
RAZORPAY_KEY_ID=your_key
RAZORPAY_KEY_SECRET=your_secret
```

### 3. Run development servers
```bash
npm run dev
```

Visit [http://localhost:5173](http://localhost:5173).
